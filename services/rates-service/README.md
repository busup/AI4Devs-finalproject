# Rates Service

**Stack:** Go (elegido para consistencia con Search Service y rendimiento).

**Responsabilidad:** Reglas de tarifas, cálculo de precios. Documentado en `docs/2_Arquitectura_del_Sistema.md` y `docs/3_Modelo_de_Datos.md`.

## Desarrollo local

```bash
go run main.go
```
